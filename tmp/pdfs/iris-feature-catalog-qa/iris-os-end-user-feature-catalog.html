About this catalog

Built from the entire project surface

Purpose

This document converts the product code, user flows, schema, API capabilities, plan rules, user manual, and product plans into language that can be used on a marketing landing page.

Availability labels

  • Available now - present in the live application code.
  • Pro / Advanced - implemented and plan-gated.
  • Available now with consent - implemented but dependent on explicit permissions and a provider connection.
  • Product-defined roadmap - specified in project plans or underlying adapters, but not exposed as a complete live module.

Copy guidance

Use the feature-set titles as landing-page sections, the one-line promises as section headlines, and the nested bullets as benefit or capability cards.

Product language

The current application brand is Iris OS. Atlas AI is the embedded intelligence layer. Older planning files use CrystalOS/Prisma terminology; this catalog normalizes those references to the current brand where the intended capability is equivalent.
