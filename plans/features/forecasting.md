# Feature Plan: Forecasting

## Goal

Build enterprise forecasting for revenue, cash flow, capacity, client churn, content performance, and agency growth.

## Screens

- Forecasting dashboard
- Revenue forecast
- Cash flow forecast
- Capacity forecast
- Client churn forecast
- Content forecast
- Scenario planner

## Build

- Show base, optimistic, and conservative scenarios.
- Include forecast inputs, assumptions, confidence, variance, and Prisma narrative.
- Connect finance, client, team, project, and creative data into forecast views.
- Add scenario controls for pipeline conversion, churn, hiring, project load, and campaign performance.

## Data

Use historical seeded metrics, forecast points, assumptions, clients, projects, team capacity, campaigns, and Prisma forecasts.

## Acceptance Checks

- Forecasts are deterministic from seed data.
- Scenario changes update visible outputs.
- Forecasting links back to source modules.
- Prisma explains risks, assumptions, and recommended actions.
