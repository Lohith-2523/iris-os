# Feature Plan: Clients

## Goal

Build client management with health intelligence, profitability, renewals, churn prediction, and upsell opportunities.

## Screens

- Client list
- Client detail
- Client health dashboard
- Renewal intelligence
- Upsell opportunities
- Client ROI view

## Build

- Create a sortable, filterable client table with health, revenue, margin, renewal date, churn risk, owner, and status.
- Add client detail pages with contacts, projects, invoices, reports, performance metrics, timeline, and Prisma insights.
- Show Client Health Score, Client Profitability Score, churn prediction, ROI analysis, and upsell recommendations.
- Include actions for generating client reports and opening related projects.

## Data

Use clients, contacts, projects, invoices, renewals, ROI metrics, health scores, upsell opportunities, and Prisma client insights.

## Acceptance Checks

- Client list and detail use the same seeded records.
- Churn and profitability scores are explainable.
- One-click client reporting links into Reporting.
- Filters and detail navigation work on desktop and mobile.
