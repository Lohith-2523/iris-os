# Feature Plan: Projects

## Goal

Build project management for delivery visibility, timeline optimization, resource planning, profitability, and risk detection.

## Screens

- Project portfolio
- Project detail
- Timeline view
- Resource allocation
- Risk register
- Milestone tracker

## Build

- Show project status, client, owner, timeline, budget, margin, overdue stages, delayed tasks, and blockers.
- Include timeline and milestone visualizations.
- Add resource recommendations and overdue stage/task explanations from Atlas.
- Link projects to clients, team members, invoices, and reports.

## Data

Use projects, clients, milestones, team members, resource allocations, project risks, profitability metrics, and Atlas project insights.

## Acceptance Checks

- Project risk is visible and actionable.
- Timeline and resource data connect to Team and Forecasting.
- Project profitability connects to Finance.
- No project detail page feels empty.
